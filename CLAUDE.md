## Commands

- `npm run dev` — Start local Wrangler dev server (port 8787)
- `npm test` — Run all tests once (Vitest)
- `npm run test:watch` — Run tests in watch mode
- `npm run typecheck` — TypeScript type check for src + test + scripts
- `npm run deploy` — Deploy to Cloudflare Workers
- `npm run build-chain-ids` — Regenerate `src/generated/chain-ids.ts` from chainid.network + DefiLlama
- `npm run generate-sdk` — Regenerate Flutter SDK from live OpenAPI spec

## Architecture

Cloudflare Workers service (Hono framework, single `src/index.ts`) that proxies DefiLlama `/protocols` data and returns a filtered, paginated DApp list per chain.

**Request flow**: Incoming GET `/api/v1/dapps?chain=...` → parse query params (chain alias resolution, group/category filter, pagination, fields projection, sort, compact/excludeSummary/includeTotal flags) → fetch protocols from DefiLlama API with in-memory cache (TTL configured via `PROTOCOLS_CACHE_TTL`) → filter by chain → map protocol to DappResource (category→group mapping, chainTvl extraction) → sort → paginate → project fields → respond.

**Key modules**:
- `src/chain-aliases.ts` — Chain name alias map (shared between app and build script)
- `src/generated/chain-ids.ts` — Auto-generated chain ID → canonical name map (661 chain IDs from chainid.network + DefiLlama /chains, generated by `build-chain-ids`)
- `src/index.ts` — Main app logic: `fetchProtocols()` (in-memory cache with TTL), `resolveCanonicalChain()` (alias + chain ID resolution), `extractChainTvl()`, `getGroupFromCategory()` (5-group taxonomy), `buildResponse()` (sort/paginate/project), `openapiSpec()` (inline OpenAPI 3.0.3)

**Testing pattern** (`test/gateway.test.ts`): Uses Vitest with `app.fetch()` (Hono's test helper, passing `mockEnv` as the bindings object). Upstream API calls are mocked via `vi.spyOn(globalThis, 'fetch')`. Cache must be reset between tests via `resetCache()` (imported dynamically because the module is re-evaluated per import).

**Flutter SDK** (`defillama-gateway-flutter/`): Auto-generated from the OpenAPI spec via OpenAPI Generator (dart client). The `generate-flutter-sdk.sh` script fetches the live spec, generates Dart files, and patches the output.

## Configuration

Set via `wrangler.toml` [vars] or `.env`:
- `DEFILLAMA_BASE_URL` — default `https://api.llama.fi`
- `PROTOCOLS_CACHE_TTL` — cache seconds (default 300)
- `REQUEST_TIMEOUT_SECS` — upstream request timeout (default 12)

## Route summary

- `GET /health` — health check
- `GET /api/v1/openapi.json` — OpenAPI spec
- `GET /api/v1/dapps?chain=...` — query DApps (see README for all query params)
